# Projekt einrichten

In diesem Abschnitt erkläre ich, wie man das Projekt auf dem eigenen Computer einrichten kann.

## Voraussetzungen

- Git muss installiert sein.
- Eine Internetverbindung wird benötigt.

## Installation

1. Öffne ein Terminal.
2. Klone das Repository:

```bash
git clone https://github.com/DEIN-USERNAME/Projekt-Dokumentation.git
```

3. Wechsle in den Projektordner:

```bash
cd Projekt-Dokumentation
```

4. Öffne die Dateien mit einem Editor deiner Wahl.

## Abschluss

Nach diesen Schritten ist das Repository lokal auf deinem Computer verfügbar.
