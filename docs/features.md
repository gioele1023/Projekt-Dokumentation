# Projektfunktionen

In diesem Abschnitt werden die wichtigsten Funktionen und Möglichkeiten von GitHub vorgestellt.

## Hauptfunktionen

- **Repositories:** Hier kann man Projekte und Dateien speichern.
- **README:** Beschreibt ein Projekt und enthält wichtige Informationen.
- **Issues:** Damit kann man Aufgaben erstellen und Probleme dokumentieren.
- **GitHub Projects:** Damit kann man Aufgaben organisieren und den Fortschritt überwachen.
- **GitHub Wiki:** Hier kann man zusätzliche Informationen und Dokumentationen sammeln.
- **GitHub Pages:** Damit kann man Webseiten direkt über GitHub veröffentlichen.
- **Gists:** Damit kann man Code und kleine Dateien einfach mit anderen teilen.

## Fazit

GitHub bietet viele Funktionen, um Projekte zu verwalten, gemeinsam daran zu arbeiten und Informationen zu dokumentieren.
